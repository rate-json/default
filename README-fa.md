# rate-json (دیفالت) — فید JSON تومانایفای (Tomanify)

این ریپازیتوری یک **اسنپ‌شات رایگان JSON از نرخ‌های بازار آزاد ارز در ایران (به تومان)** برای ارزهای زیر منتشر می‌کند:
**دلار (USD)، یورو (EUR)، درهم امارات (AED)، لیر ترکیه (TRY)، یوان چین (CNY)**.

این پروژه توسط **امین رئوفی** نگهداری می‌شود و منبع اصلی داده‌های افزونه وردپرس/ووکامرس **Tomanify** است:
- افزونه: https://wordpress.org/plugins/tomanify

---

## این پروژه چیست؟
یک **فید داده JSON** عمومی و سبک که برای توسعه‌دهندگان و صاحبان وب‌سایتی طراحی شده که به یک اندپوینت ساده و سریع برای دریافت آخرین نرخ‌های ارز نیاز دارند.

- **تعداد به‌روزرسانی:** ۳ الی ۴ بار در روز
- **فرآیند:** نرخ‌ها روی یک سرور خارجی جمع‌آوری، بررسی و اعتبارسنجی شده و در نهایت یک اسنپ‌شات یکپارچه در اینجا منتشر می‌شود.

---

## داده‌ها
- واحد پایه: **تومان**
- ارزهای موجود: **USD / EUR / AED / TRY / CNY**
- فایل: `data.json`

> نکته: فیلدهای دقیق فایل JSON ممکن است توسعه یابند، اما مقادیر ارزها همیشه تحت کدهای استاندارد و ثابت ارزی ارائه می‌شوند.

## سلب مسئولیت حقوقی
این پروژه یک ابزار متن‌باز، غیرتجاری و صرفاً با اهداف پژوهشی، آموزشی و فنی است. این فید تنها به عنوان یک جمع‌آوری‌کننده (Aggregator) داده‌های عامه و منتشرشده در فضای وب عمل می‌کند و هیچ‌گونه نقشی در قیمت‌گذاری، اعلام نرخ رسمی، مداخله در بازار یا معامله‌گری ارز ندارد.

این داده‌ها **به صورت رایگان و «همان‌طور که هست»** ارائه می‌شوند و هیچ‌گونه تضمینی در خصوص دقت، لحظه‌ای بودن یا تداوم ارائه آن وجود ندارد. مسئولیت استفاده از این داده‌ها بر عهده کاربر است.
