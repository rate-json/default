# Project moved to Tebaro

This legacy repository has been retired as part of the Tomanify → Tebaro project transition and the move to a coefficient-only public publishing model.

Current public coefficient repository:
https://github.com/tebaro-wp/coefficient-index

Project documentation:
https://tomanify.github.io/

Legacy per-currency public rate files are no longer published from this repository.
